KaterOnyx

FFA client, loaded on Senpa's official web origin — same host logic as JaxxV6, without the Jaxx app.

Install Tampermonkey script
  1. Install Tampermonkey.
  2. Serve this folder: npx --yes serve -p 4173
  3. Click install above and confirm the script.
  4. Reinstall/update the userscript if it was already installed (version 1.9.9).
  5. Open https://senpa.io/web/.
Do not open onyx-ffa-page.html or ffa/client.html as the game host. The userscript must run on senpa.io so the FFA server sees Senpa's official Origin. After updating, disable JaxxV6 / other Senpa scripts, then hard-refresh https://senpa.io/web/. Success looks like the ONYX menu, PIXI on #canvas, console [ONYX-ENGINE] / THEME_INLINED = true, and PLAY going through deo.onyx (not ONYXFfa). If the script cannot fetch files, run this in the senpa.io console:
localStorage.setItem("kateronyx:base-url","http://127.0.0.1:4173/")
